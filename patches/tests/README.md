# 다운로드 폴더 저장 검증

두 테스트는 같은 서명의 진단용 APK에 instrumentation으로 등록해 각각 티맵과 네이버지도를 대상으로 실행합니다. Android 10 이상의 실기기에서 MediaStore 저장·SHA256·동일 파일 재사용·잘못된 해시 거부·설치 요청 권한 제거·완료 알림을 확인합니다.

설치된 APK 자체를 다운로드 폴더로 복사해 검증하며, 설치 화면을 실행하지 않습니다. 정상 APK는 다운로드 폴더에 남깁니다. 잘못된 해시 검사용 임시 항목은 저장 코드가 삭제합니다. 테스트 APK는 검증 후 제거합니다.

2026.11.17.2 수정본을 갤럭시 S21+ / Android 15에서 두 앱 모두 통과했습니다. 테스트에서 사용하는 기존 진단 APK 패키지 이름은 호환성을 위해 유지했습니다.
